# pagetext-kit

**新站的寫法：畫面上給人看的字不寫在標籤裡，集中放每頁的內容檔。附自動檢查（違反就不給過）、給 AI 的規則、帶變數的字串小工具** 零依賴、框架無關。

## 安裝

```bash
npm i github:Jeffrey0117/pagetext-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('pagetext-kit');
const x = create({ /* opts */ });
```
